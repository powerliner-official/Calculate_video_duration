# Calculate video duration by python
In this project, the calculation of video duration is implemented via Python code integrated into the PyCharm software. Designed for engineers who have participated in the comprehensive control course offered by Powerliner, this project is provided in its entirety as an open-source resource.
# محاسبه مدت‌زمان ویدیو با پایتون و کتابخانه OpenCV
در این پروژه، محاسبه مدت‌زمان ویدیو از طریق کدهای پایتون که در نرم‌افزار PyCharm پیاده‌سازی شده‌اند، انجام می‌شود. این پروژه که برای مهندسان شرکت‌کننده در «دوره جامع کنترل» (ارائه‌شده توسط مجموعه Powerliner) طراحی شده، به‌طور کامل و به‌عنوان یک منبع متن‌باز (Open-source) در دسترس قرار گرفته است.
# نصب کتابخانه OpenCV 
برای اجرای این پروژه نیاز است که کتابخانه openCV نصب شده باشد که این کار روی فایل پروژه توسط بنده انجام شده است.اما درصورت بروز هرگونه مشکل و ارور مبتنی بر عدم نصب کتابخانه می‌توانید از طریق دستور pip install opencv-python این کتابخانه را به پروژه ی خود اضافه و نصب کنید.
